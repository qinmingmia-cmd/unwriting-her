# Drafts (not published)

This branch holds work that is **not** on unwritingher.com. Netlify publishes only `main`, so nothing here goes live.

- `thornfield-rooms.html`: prototype 2 (explorable house). It has a house plan, Jane's room, Grace Poole's room and the third-storey corridor; a satchel; and three tasks: developing the mirror's prints, taking Grace Poole's keys, and turning the lock. Open the file in a browser to play.
- `hearing-table.html`: prototype 1 (the hearing table, stamps, candlelit room).
- `../source/`: the full source of the game and both prototypes. Run `python3 build.py`, `python3 proto/build.py` or `python3 proto2/build.py` to rebuild.
